# Native Studio parity checklist

Baseline: the initial twelve user-supplied Native Studio screenshots, seventeen additional structured-editor references, and two Form/JSON toggle references reviewed on October 8, 2026. The additional Work Order screenshot shows Workbench, not Native Studio. Screenshots establish visible workflows, not undocumented server APIs or behavior hidden behind buttons. This is an audit, not a claim of complete feature parity.

## UX direction

Keep the selected graphite adaptive master/detail design. Use content names rather than package implementation keys for primary navigation; retain exact keys in secondary text and source editing. Put counts, pending-change status and action consequences adjacent to controls. Technical diagnostics stay collapsed. Phone menus and previews must remain within the viewport or explicitly offer actual-size scrolling.
